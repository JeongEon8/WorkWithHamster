# Privacy Policy — Hamster Buddy

**Last updated: May 25, 2025**

---

## 1. Overview

Hamster Buddy ("the Extension") is a Chrome extension that displays an animated hamster overlay on web pages that reacts to keyboard input. This policy explains how the Extension handles user data.

---

## 2. Data Collection

**Hamster Buddy does not collect any user data.**

The Extension does not:
- Collect, store, or transmit any personal information
- Record or log keyboard input
- Access browsing history or web content
- Use cookies or any tracking technology
- Communicate with external servers

---

## 3. Permissions

The Extension uses the `content_scripts` permission with `<all_urls>` solely to inject the hamster animation overlay into web pages and detect keyboard activity locally within the browser. No data is extracted or transmitted as a result of this permission.

---

## 4. Third Parties

Hamster Buddy does not share any information with third parties. No analytics, advertising, or data-sharing services are used.
